# Architecture decision records

This folder holds architecture decision records (ADRs) for the Strategic Portfolio Management application. The [solution overview](../solution-overview.md) describes the current target architecture.

Add each significant decision as a separate Markdown file named `NNNN-short-decision-title.md`. Record the context, options considered, decision, consequences, status and date. Keep superseded decisions for the historical record and link to the decision that replaces them.

No ADRs have been recorded yet.
